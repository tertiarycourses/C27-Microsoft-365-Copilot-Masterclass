# Current capability sources

Checked 13 October 2026. Course instructions summarise capabilities; feature visibility depends on the assigned account and tenant.

- [Excel custom skills](https://support.microsoft.com/en-us/excel/copilot/copilot-in-excel-skills): matching folder and SKILL.md, app-created OneDrive folder, Refresh and invocation.
- [PowerPoint custom skills](https://support.microsoft.com/en-us/powerpoint/copilot/copilot-in-powerpoint-skills): upload/form/OneDrive routes and separate app discovery.
- [Word drafting](https://support.microsoft.com/en-gb/word/copilot/draft-and-add-content-with-copilot-in-word): current-document drafting and explicit source references.
- [Supported file formats](https://support.microsoft.com/en-us/microsoft-365-copilot/file-formats-supported-by-microsoft-365-copilot): supported app reference formats; inaccessible local paths do not supply content.
- [PowerPoint file grounding](https://support.microsoft.com/en-us/powerpoint/copilot/add-a-slide-from-a-file-with-copilot-in-powerpoint): select the source file explicitly.
- [Excel dashboard design](https://support.microsoft.com/en-us/excel/create-and-share-a-dashboard-with-excel-and-microsoft-groups): multiple PivotTables/charts and filter connections.
- [Slicer filtering](https://support.microsoft.com/en-us/excel/get-started/use-slicers-to-filter-data): same-source PivotTables and explicit connections.

Course design choices: a fixed synthetic reporting date, a reviewed Word bridge for dashboard-to-presentation grounding, dropdown/formula interactions as the portable primary dashboard route, optional connected PivotTable slicers, and manually logged cross-app chats. Native tenant skill execution must be checked in class; generated checkpoints are deterministic examples.
