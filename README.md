# C027 — Microsoft 365 Copilot Masterclass

Aligned non-WSQ courseware for the one-day Microsoft 365 Copilot Masterclass.

- Course code: C027
- Duration: 7.5 instructional hours
- Topics: 2
- Connected labs: 8
- Version: v1.0

## Courseware

- Trainer slide deck and learner-slide PDF: `courseware/`
- Learner Guide DOCX/PDF: `courseware/`
- Learner Guide Markdown mirror: repository root
- Lesson Plan DOCX/PDF: `courseware/`
- Standalone labs and synthetic assets: `labs/`

The repository-local generation pipeline uses `course_data.py` and
`data_domain1.py` / `data_domain2.py` as the single source for the PPT,
Learner Guide, Lesson Plan and labs.
