# Asteron Decision Deck Specification

**Audience:** Department heads  
**Purpose:** Confirm the internal pilot position and make the remaining decision visible  
**Length:** Exactly six slides

## Required sequence

1. Decision needed
2. Pilot scope
3. Readiness snapshot
4. Timeline and owners
5. Risks and open question
6. Next actions

## Visual and content rules

- One message per slide.
- Every factual slide has Source ID notes in speaker notes.
- The timeline contains only four approved milestones.
- In Lab 3, the readiness slide shows dependencies and status only; do not add numerical readiness measures before Lab 4.
- Numerical readiness measures may be added later only from the verified Lab 4 Excel workbook and must trigger a new deck version.
- The support-clinic room remains open.
- Decorative imagery must not imply real client, participant or operational evidence.
- Use readable contrast, logical reading order and meaningful alternative text.
- Run PowerPoint's Accessibility Checker and record the result in the final notes.
