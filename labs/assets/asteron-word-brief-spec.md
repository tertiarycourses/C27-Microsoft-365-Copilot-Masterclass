# Asteron Word Brief Specification

## Audience and purpose

Department heads need a concise internal position before the controlled pilot. The document should help them understand what is confirmed, what still needs work and who owns each next action.

## Required structure

1. Purpose and Audience
2. Confirmed Launch Position
3. Readiness and Dependencies
4. Decisions and Owners
5. Open Questions and Next Actions

## Boundaries

- One to two pages including the release table.
- Use only verified claims from the source register.
- Use ISO dates.
- Keep the support-clinic room open.
- Do not imply that an external announcement has been approved.
- Add a `[Source_ID]` note for each material fact.

## Release record

The final document needs a reviewer, date, version and one state: Approved for deck handoff, Revise or Hold.
